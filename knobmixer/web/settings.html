    Knobs

    Each knob controls one channel. Keys are optional: use them for hotkeys, or leave them empty if the knob is only used from a serial device or the on-screen mixer. Click ⏺ and press a key combo to record it (Backspace clears, Esc cancels). F13–F24 are safest: no normal keyboard has them, so they never clash with anything.

    Input methods

    The device sends one line per event, naming a knob by its position or id: 1 +1 turn right, 1 -1 turn left, 1 press toggle mute, 1 set 42 absolute position (for faders).

    Faders and mute buttons for every knob, for any phone or tablet on your WiFi. Settings stay on this PC. Windows Firewall blocks other devices until you run tools\allow-phone-firewall.ps1 once as admin.
